# บันทึกการผสมเคมีบำบัด (ChemoPrep) · CH9 Airport

หน้าเว็บ: https://watanyutocharoen.github.io/ch9-chemo-pharmacist/chemoprep/

- **หน้าเว็บ** (โฟลเดอร์นี้) โฮสต์บน GitHub Pages — ใช้ `../data.js` และ `../lib.js` ร่วมกับแอปเภสัชกรเคมีบำบัด (สูตรยา/ตรวจขนาดยาชุดเดียวกัน)
- **ข้อมูล** อยู่ใน Google Sheet ของฝ่ายเภสัชกรรม เรียกผ่าน Apps Script (`backend/Code.gs`) — **ไม่มีข้อมูลผู้ป่วยใน repo นี้**
- `config.js` = URL ของ Apps Script Web app (ลงท้าย `/exec`)

## ติดตั้ง backend
1. เปิด Google Sheet ข้อมูล → ส่วนขยาย → Apps Script → วางโค้ด `backend/Code.gs` แทนของเดิม → บันทึก
2. เลือกฟังก์ชัน `setupSheets` → เรียกใช้ → อนุญาตสิทธิ์
3. การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท **เว็บแอป** · เรียกใช้ในฐานะ **ฉัน** · ผู้ที่มีสิทธิ์เข้าถึง **ทุกคน**
4. คัดลอก URL `/exec` ใส่ใน `config.js`

แก้โค้ดภายหลัง: การทำให้ใช้งานได้ → จัดการ → แก้ไข → เวอร์ชันใหม่ (URL เดิม)
