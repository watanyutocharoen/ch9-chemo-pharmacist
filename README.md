# เภสัชกรเคมีบำบัด โรงพยาบาลจุฬารัตน์ 9 แอร์พอร์ต

เว็บแอปช่วยเภสัชกรค้นหาสูตรยาเคมีบำบัดและยามุ่งเป้า (Targeted therapy / Immunotherapy) คำนวณขนาดยา (BSA, mg/kg, Calvert/AUC) และ **ตรวจสอบขนาดยาที่แพทย์สั่ง** เทียบกับขนาดมาตรฐาน

> ⚠️ เป็นเครื่องมือช่วยตรวจสอบ (double-check) ไม่ใช่คำสั่งการรักษา ขนาดยาต้องยืนยันกับ protocol ของโรงพยาบาลและแพทย์ผู้สั่งเสมอ · แอปไม่บันทึกหรือส่งข้อมูลผู้ป่วยออกไปที่ใด (คำนวณในเบราว์เซอร์ทั้งหมด)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ | ต้องแก้เมื่อ |
|---|---|---|
| `data.js` | **ฐานข้อมูลสูตรยา** (ชนิดมะเร็ง + สูตร + ขนาดยา) | เพิ่ม/แก้/ลบสูตร ← แก้ไฟล์นี้เป็นหลัก |
| `lib.js` | ข้อมูลยารายตัว: กลุ่มยา, ปรับขนาดตามไต/ตับ, ขนาดสะสม, ข้อควรระวัง | มียาตัวใหม่ที่ยังไม่มีในระบบ |
| `app.js` | ระบบคำนวณและหน้าจอ | ไม่ต้องแก้ (นอกจากเปลี่ยนการทำงาน) |
| `index.html` | หน้าเว็บ, สไตล์, หน้าวิธีคำนวณ/อ้างอิง | แก้ข้อความหน้าอ้างอิง |
| `logo.png` | โลโก้โรงพยาบาล | — |

## วิธีเพิ่มสูตรใหม่ (ทำผ่านเว็บ GitHub ได้เลย ไม่ต้องติดตั้งอะไร)

1. เปิดไฟล์ `data.js` ใน GitHub แล้วกดรูปดินสอ ✏️ (Edit)
2. หาหมวดมะเร็งที่ต้องการ (เช่น `// ---------------- LUNG ----------------`) แล้ววางสูตรใหม่ต่อท้ายหมวดนั้น ตามแบบนี้:

```js
{ c:'lung', n:'ชื่อสูตร', s:'ข้อบ่งใช้/ระยะโรค', cy:'q21 วัน × 4', ref:'ชื่อ trial / แหล่งอ้างอิง', d:[
  d('Carboplatin',5,'AUC','D1','IV'),
  d('Pemetrexed',500,'mg/m2','D1','IV'),
  d('Pembrolizumab',200,'mg','D1','IV')
], note:'หมายเหตุของสูตร (ไม่ใส่ก็ได้)'},
```

3. อัปเดตเลขเวอร์ชันบรรทัดบนสุด เช่น `const DB_VERSION = 'v1.1 (1 ธ.ค. 2569)';`
4. กด **Commit changes** และเขียนสั้นๆ ว่าแก้อะไร (เช่น "เพิ่มสูตร X ตาม protocol ที่ทีม onco รับรอง") แล้วรอประมาณ 1–2 นาที หน้าเว็บจะอัปเดตเอง

### รูปแบบ `d(ชื่อยา, ขนาด, หน่วย, วันที่ให้, วิธีให้, {ตัวเลือก})`

| หน่วย | ความหมาย | ตัวอย่าง |
|---|---|---|
| `'mg/m2'` | คูณ BSA | `d('Docetaxel',75,'mg/m2','D1','IV')` |
| `'mg/kg'` | คูณน้ำหนัก | `d('Bevacizumab',15,'mg/kg','D1','IV')` |
| `'mg'` | ขนาดคงที่ | `d('Pembrolizumab',200,'mg','D1','IV')` |
| `'AUC'` | Carboplatin (สูตร Calvert) | `d('Carboplatin',5,'AUC','D1','IV')` |
| `'units/m2'`, `'units'` | หน่วย units (เช่น bleomycin) | `d('Bleomycin',30,'units','D1, D8, D15','IV')` |
| `'tier'` | ขนาดตามช่วงน้ำหนัก | ดูตัวอย่าง Lenvatinib ใน `data.js` |

ตัวเลือกเพิ่มเติม (ใส่ในวงเล็บปีกกา `{ }` ท้ายสุด ไม่ใส่ก็ได้):

- `cap:2` ขนาดสูงสุดต่อครั้ง (mg) เช่น vincristine
- `freq:'BID'` ยารับประทานวันละ 2 มื้อ (ขนาดที่ใส่คือต่อมื้อ)
- `nDays:4` ยาหยดต่อเนื่องที่ใส่ขนาดเป็นต่อวัน แอปจะแสดงขนาดรวมต่อรอบให้ด้วย
- `roundTo:150` ปัดขนาดตามเม็ดยา
- `note:'...'` หมายเหตุของยาตัวนั้น

รหัสชนิดมะเร็ง (`c:`): `breast` `crc` `gastric` `hcc` `biliary` `pancreas` `lung` `hn` `cervix` `ovary` `endomet` `bladder` `prostate` `kidney` `gct` `lymphoma` `myeloma` `leukemia` `other` (เพิ่มหมวดใหม่ได้ที่ `CANCERS` และ `CANCER_KW` ต้นไฟล์)

### ถ้าเป็นยาตัวใหม่ที่ยังไม่มีในระบบ
เพิ่มบรรทัดใน `lib.js` ในวัตถุ `DL` เช่น

```js
newdrugname: { cls:'targeted', note:'ข้อควรระวัง', hep:'การปรับขนาดเมื่อตับบกพร่อง' },
```

ใช้ชื่อคำแรกของยาเป็นตัวพิมพ์เล็ก ส่วน `cls` เลือกได้จาก `chemo` / `targeted` / `io` / `hormone` / `support`

### ข้อควรปฏิบัติ
- ทุกการเพิ่ม/แก้ขนาดยา **ควรผ่านการรับรองของแพทย์หรือเภสัชกรด้านมะเร็ง** และอ้างอิงแหล่งที่มาในช่อง `ref`
- ระวังเครื่องหมาย `,` `'` และวงเล็บให้ครบ ถ้าพิมพ์ผิดหน้าเว็บจะไม่แสดงรายการสูตร (ย้อนกลับได้ในแท็บ History ของ GitHub)
- ทดสอบหลังแก้ทุกครั้ง โดยเปิดหน้าเว็บ ค้นหาสูตรที่เพิ่ม แล้วใส่ข้อมูลผู้ป่วยตัวอย่าง
